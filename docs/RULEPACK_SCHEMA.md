# RULEPACK_SCHEMA.md — signed, versioned clinical rule pack

The pack is generated by `tools/cpic_ingest` from CPIC data. **Never hand-write
recommendation text.** Values in angle brackets come from CPIC at ingest time.

```json
{
  "schemaVersion": 2,
  "packVersion": "1.4.0",
  "cpicSnapshot": "<ISO date of CPIC data pull>",
  "genomeBuilds": ["GRCh38", "GRCh37"],
  "genes": {
    "CYP2C19": {
      "callable": "full",
      "alleles": {
        "*2": { "function": "<from CPIC>", "defining": [
          { "rsid": "<rsid>", "build": "GRCh38", "chrom": "<chr>", "pos": 0, "ref": "<ref>", "alt": "<alt>" } ] }
      },
      "phenotypeMap": {
        "<diplotype or score range>": "<CPIC phenotype term>"
      }
    }
  },
  "drugs": {
    "clopidogrel": {
      "rxnorm": "<id>",
      "brands_in": ["<Indian brand names from dictionary>"],
      "rules": [
        {
          "id": "clopidogrel-cyp2c19-v3",
          "genes": ["CYP2C19"],
          "cpicGuidelineRef": "<guideline citation + version>",
          "evidenceLevel": "<A|B>",
          "population": "adult",
          "when": [
            { "gene": "CYP2C19", "phenotype": "Poor Metabolizer" }
          ],
          "severity": "high_risk",
          "recommendation": { "en": "<CPIC wording, paraphrased only by clinical reviewer>", "hi": "<reviewed translation>", "mr": "<reviewed translation>" },
          "alternatives": [ { "generic": "<drug>", "note": "<CPIC note>" } ],
          "contextNotes": ["<e.g., indication-specific: ACS/PCI>"]
        }
      ]
    }
  },
  "banners": { "<context>": { "en": "...", "hi": "...", "mr": "..." } },
  "killSwitch": []
}
```

- `packVersion` semver: MAJOR = schema/logic break, MINOR = new gene-drug pairs,
  PATCH = text/evidence corrections.
- `callable`: `full` | `partial` | `lab_only` (e.g., CYP2D6 with CNV from a plain VCF).

## Pack integrity
File `pack-<version>.json` + `pack-<version>.sha256` + `pack-<version>.sig`
(Ed25519 over the SHA-256). The app embeds the public key. Implement
`RulePackVerifier.verify(bytes, sig)` and refuse unsigned packs in release builds
(debug builds may allow a dev key).

## Validation tools
1. JSON-schema validation of every pack.
2. `pharmcat_validate`: run PharmCAT on a corpus of synthetic VCFs and assert our
   diplotypes/phenotypes match for all genes marked `callable: full`. Mismatch fails CI.
3. Snapshot test: a changed recommendation string requires a changelog entry and a
   signoff field.
